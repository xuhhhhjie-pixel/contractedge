# 精确定位已有诊断图的纠错缺口

依据：source056 KPT 第一次诊断已有两个带当前源码的生产消费者，但配置到观测的边绕过了它们。校验正确拒绝；唯一格式纠错只收到抽象路径错误，随后新增一个只有观察引用的消费者，再次正确拒绝。新增错误并非第一次输出已存在，不能通过初次错误聚合预知。

选择：在既有 PRODUCTION_PATH_INCOMPLETE 纠错回合中附带拒绝图的有界清单。相比增加调用次数，直接指出已有节点与端点更接近已观察根因；相比自动补边，它不替代模型的语义判断。只陈列原始模型节点/关系和既有请求中通过快照、摘要核对的源码引用，不能声明任何节点角色或因果关系已经被证实。

清单最多4096 UTF-8字节；每类最多8条，完整记录装入，遗漏数量明确。区分配置、源码锚定消费者、无当前源码消费者、终端及实际关系。源码身份取自最近的可信 user 请求（run_context/evidence_catalog），不从拒绝模型的 evidence_refs 中接受新记录；不读取新文件。旧请求、拒绝回答和校验规则不改，不增加调用、Top12、扩展或编辑额度。
